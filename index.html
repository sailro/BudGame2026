JOUER EN LIGNE

Pair-à-pair : le combat lui-même ne passe par aucun serveur. Un relais public gratuit sert uniquement de point de rendez-vous pendant la poignée de main (~700 octets, chiffrés), puis il est abandonné.

Options avancées — relais TURN (si la connexion échoue)

Par défaut le jeu est 100 % pair-à-pair. Si votre réseau bloque la connexion directe (NAT symétrique, pare-feu d'entreprise), collez ici les identifiants d'un relais TURN gratuit (ExpressTURN, Metered…). Stocké dans ce navigateur uniquement. Seul l'hôte a besoin de le configurer : les identifiants voyagent dans l'invitation, ne la partagez donc qu'avec votre adversaire.

Collez l'adresse telle que fournie par votre relais : le préfixe turn: est ajouté automatiquement, et les variantes UDP et TCP sont essayées toutes les deux.

Options avancées — appairage manuel (sans aucun tiers)

Si les relais de rendez-vous sont injoignables, vous pouvez échanger les codes à la main : l'hôte envoie une invitation, le client renvoie une réponse. Aucun tiers n'intervient, mais il y a un aller-retour.
